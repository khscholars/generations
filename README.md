# Generations over Dinner

Participant directory for Generations over Dinner, hosted by Knight-Hennessy Scholars with the Distinguished Careers Institute. Thursday, November 12, 2026, Denning House.

## Publishing with GitHub Pages

1. Upload `index.html` to the root of this repository (Add file, then Upload files).
2. Go to Settings, then Pages.
3. Under Build and deployment, set Source to "Deploy from a branch," choose `main` and `/ (root)`, and save.
4. The site appears at https://khscholars.github.io/generations/ within a few minutes.

## Updating

Everything the page shows, including bios and photos, is stored inside `index.html`. To update it, replace that file with a new version and commit. The site refreshes within a few minutes.

The page asks search engines not to index it.
